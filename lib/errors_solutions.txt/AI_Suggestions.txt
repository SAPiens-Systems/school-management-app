## ⚙️ How to Integrate AI with Flutter + Firebase

### Option 1: **Call AI APIs directly from Flutter**

* Use `http` package to send a request to OpenAI / Gemini API.
* Process the response and display in the app.
* 🔒 Downside: You’d expose your API key in the app → **not secure**.

### Option 2: **Use Firebase Cloud Functions (Recommended)**

* Write a Firebase Cloud Function (Node.js or Python).
* Cloud Function calls the AI API (OpenAI, Gemini, etc.).
* Flutter app calls your function securely via Firebase SDK.
* ✅ API key stays safe on the server.

---

## Example Flow (Report Card Comment Generator)

1. Teacher enters marks → stored in Firestore.
2. Flutter app calls a Cloud Function: `generateReportComment(studentId)`.
3. Cloud Function fetches marks → sends request to OpenAI API with a prompt like:
   *“Generate a report card comment for a student with these marks: Math 92, Science 70, English 80.”*
4. AI returns the text → stored in Firestore.
5. Flutter app displays the AI-generated comment to the teacher (teacher can edit before finalizing).
